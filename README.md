# PG Hostel Management System (SQL Project)

## 📌 Project Overview

The **PG Hostel Management System** is a database management project designed to manage student information in a PG hostel.

This project uses SQL to store, retrieve, and manage student records efficiently. It demonstrates basic database operations and SQL query execution.

## 🎯 Project Objectives

- Store student information in a database.
- Retrieve student details using SQL queries.
- Understand database management concepts.
- Practice SQL commands and database operations.

## 🛠️ Technologies Used

- **Database:** MySQL
- **Query Language:** SQL
- **Tools:** MySQL Workbench

## 🗄️ Database Operations

The current SQL file contains the following query:

### Display All Student Records

```sql
SELECT * FROM students;
```

This query retrieves all records and columns from the `students` table.

## ⚙️ How to Run the Project

1. Install MySQL Server on your computer.
2. Open MySQL Workbench.
3. Create or select your project database.
4. Make sure the `students` table exists.
5. Open the `PG Hostel management project.sql` file.
6. Execute the SQL query.
7. View the student records in the result section.

## 📚 Learning Outcomes

- Understanding relational databases.
- Writing and executing SQL queries.
- Retrieving records from database tables.
- Understanding basic database operations.
